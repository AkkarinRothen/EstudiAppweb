# Feature Map - EstudiApp

## Dashboard
- Ver prioridades del dia
- Detectar proximos examenes o entregas
- Sugerir tecnica recomendada
- Mostrar recomendaciones accionables por vencimientos, examenes, carga y foco reciente

## Navigation
- Mantener una barra inferior compacta con accesos principales y menu Mas para herramientas secundarias
- Resaltar el destino principal activo tambien desde pantallas de detalle

## Calendar
- Ver agenda semanal de tareas, evaluaciones, clases y sesiones de estudio
- Navegar entre semanas
- Abrir materia o curso desde eventos relacionados

## Planner
- Crear tareas de estudio
- Marcar prioridad
- Ver progreso por materia
- Cambiar entre modo Estudiante y modo Maestro para separar flujos de estudio y docencia
- Recordar el modo activo del planificador como preferencia persistida
- Guiar primeros pasos segun el modo cuando faltan datos iniciales
- Crear tareas desde plantillas inteligentes con checklist automatico
- Editar tareas y evaluaciones existentes sin recrearlas
- Editar clases planificadas existentes sin recrearlas
- Generar estructura de clase con presets generales y de ingles: grammar, speaking, reading, vocabulary y evaluacion corta
- Completar o reemplazar la estructura didactica desde el editor de una clase
- Mover una clase planificada una semana hacia atras o adelante desde el editor
- Editar metadatos de materiales sin recrearlos
- Crear multiples subtareas pegando varias lineas y marcar/reabrir checklists completos
- Duplicar tareas, evaluaciones y materiales como base reutilizable
- Armar estructura base para clases con inicio, desarrollo, cierre y recursos
- Planificar dias recurrentes de clase para un curso y generar varias clases planificadas por rango de fechas

## Techniques
- Explicar tecnicas con lenguaje accionable
- Mostrar cuando usar cada tecnica
- Convertir cada tecnica en pasos concretos

## Review
- Armar cola de repaso desde tareas, evaluaciones y materiales
- Priorizar pendientes por urgencia, estado y prioridad
- Abrir materiales o materias desde cada sugerencia

## Search
- Buscar en tareas, materias, materiales, evaluaciones, clases, secuencias y cursos
- Abrir resultados navegables sin duplicar logica de detalle
- Mantener la busqueda como feature independiente sobre datos de dominio

## Reports
- Resumir foco acumulado, clases dadas, clases planificadas, asistencia y secuencias abiertas
- Mostrar reportes por curso con asistencia promedio, pendientes docentes y calificaciones
- Abrir el curso desde cada reporte

## Teaching
- Medir preparacion de cada clase segun objetivo, momentos didacticos, recursos, materiales y pendientes docentes
- Detectar rapidamente que falta antes de llevar una clase al aula
- Planificar la siguiente clase desde una clase existente, conservando estructura y limpiando registro real
- Gestionar lista de estudiantes por curso: agregar, editar y sacar estudiantes
- Registrar asistencia por estudiante y clase con presente/ausente/se retiro, trabajo realizado y llamados de atencion
- Tomar asistencia con guardado rapido al tocar estado de asistencia o trabajo
- Aplicar acciones masivas por clase: todos presentes, todos ausentes y copiar asistencia anterior
- Detectar estudiantes que requieren seguimiento por faltas, retiros, falta de trabajo, tareas y llamados
- Mostrar prioridades de planificacion por curso: proxima clase, clases vencidas, cierres pendientes y secuencias por completar
- Filtrar asistencia por estudiantes con alertas o registros pendientes
- Ver asistencia acumulada por estudiante con porcentaje, faltas, retiros, falta de trabajo y llamados
- Ver avance de secuencias con clases dadas, clases planificadas, pendientes docentes y contenido pendiente

## Material Organizer
- Guardar apuntes, links y recursos
- Asociar materiales a materias o temas
- Preparar base para repaso futuro
