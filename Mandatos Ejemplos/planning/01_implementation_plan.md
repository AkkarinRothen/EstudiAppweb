# Plan de Implementacion - EstudiApp

## Stack base
- Android nativo
- Kotlin + Compose
- Hilt para DI
- Room para persistencia local
- Navigation Compose
## Fase 1 - Cimentacion
- Scaffold modular
- Dashboard inicial
- Planner de tareas de estudio
- Catalogo de tecnicas

## Fase 2 - Organizacion del material
- Materias
- Unidades/temas
- Materiales por tipo: resumen, PDF, video, enlace, practica
- Etiquetas de dificultad, avance y fecha objetivo

## Fase 3 - Sesiones de estudio
- Temporizador de foco
- Sesiones Pomodoro
- Registro de tiempo real
- Historial por materia y tecnica

## Fase 4 - Inteligencia academica ligera
- Recomendaciones de tecnica segun objetivo
- Deteccion de carga excesiva semanal
- Sugerencias de repaso espaciado

## Fase 5 - Editor Avanzado y Zettelkasten
Ver `EPIC_advanced_editor.md` para detalles.

## Fase 6 - Mapa de Conocimiento y OCR
Ver `EPIC_knowledge_map_ocr.md` para detalles.

## Fase 7 - Aprendizaje Activo (Active Recall)
Ver `EPIC_active_recall.md` para detalles.

## Fase 8 - El Estudiante AI-First (Audio e IA Contextual)
Ver `EPIC_ai_first_student.md` para detalles.

## Fase 9 - Editor Multimodal (Dibujo y Split View)
Ver `EPIC_multimodal_editor.md` para detalles. Incluye:
- Pestañas de dibujo interactivo (Infinite Canvas).
- Vista dividida (Split View) para comparar o editar dos secciones.
- Inserción de diagramas en notas de texto.

## Principios
- Primero resolver claridad y ejecucion; luego automatizacion.
- Toda feature debe aportar accion, no solo informacion.
- Minimizar friccion al capturar tareas o materiales.
