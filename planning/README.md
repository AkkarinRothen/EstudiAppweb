# Planificación de EstudiApp Web

Este directorio contiene la documentación estratégica y técnica del portal web de EstudiApp.

## Documentos Disponibles

- **[ARCHITECTURE.md](./ARCHITECTURE.md):** Descripción detallada de la estructura de módulos ES6, capas de datos y flujo de información.
- **[WORKFLOW.md](./WORKFLOW.md):** Guía paso a paso para añadir contenido, modificar lógica y publicar cambios.

## Objetivos del Proyecto Web

1. **Accesibilidad Universal:** Permitir que los estudiantes accedan a sus materiales de estudio desde cualquier navegador sin instalar la aplicación.
2. **Interactividad Ligera:** Ofrecer una experiencia de estudio fluida (SRS, TTS, Feedback visual) usando tecnologías web nativas.
3. **Sincronización Conceptual:** Mantener la misma lógica de aprendizaje que la aplicación nativa de Android.
4. **Mantenimiento Sencillo:** Facilitar la creación de nuevos packs mediante un sistema de plantillas y automatización.
