# EstudiApp - Portal de Recursos

Este repositorio contiene las herramientas didácticas interactivas generadas por la aplicación **EstudiApp**.

## Estructura
- `index.html`: Catálogo principal de recursos.
- `presets/`: Contiene las tablas interactivas de vocabulario en formato HTML.

## Cómo publicar
1. Sube los archivos a la rama `main`.
2. Ve a **Settings** -> **Pages**.
3. En **Build and deployment**, selecciona la rama `main` y la carpeta `/(root)`.
4. Pulsa **Save**.

Los estudiantes podrán acceder a los recursos mediante la URL proporcionada por GitHub Pages.
